## Método de continuidade

1. Usar a tarefa correspondente para registrar requisitos e critérios de aceite.
2. Trabalhar em alterações pequenas, com validações proporcionais.
3. Conferir o resultado das verificações automáticas no GitHub a cada envio.
4. Registrar evidências e pendências antes de considerar uma entrega concluída.
5. Tratar configuração de produção, dados reais, custos e publicação como entregas próprias.

A recuperação do SEMPER BI foi mantida fora da branch principal para permitir comparação e revisão. A compilação e os testes não comprovam equivalência integral com a última instalação oficial nem substituem a homologação com dados fictícios.
